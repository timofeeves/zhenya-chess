# zhenya-chess

Шахматные партии для разбора.

## Импорт партии из Lichess

1. Открой вкладку **Actions** → **Import Lichess game**.
2. Нажми **Run workflow** и вставь ссылку на партию.
3. После завершения PGN появится в папке `games/`.

Скрипт сохраняет только первые 8 символов ID партии. Поэтому приватный хвост ссылки из 4 символов не попадает в публичный репозиторий.
